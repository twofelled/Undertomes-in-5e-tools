**The Undertomes in 5e.tools** is a curated conversion project that makes publicly available Undertomes homebrew content usable in the 2014 version of 5e.tools.

## Choose a file

**For the complete Project Moon collection you can load the Project Moon JSON.** It contains 76 sources, including the General Rules for LC Conditions. Each brew has its own source abbreviation and book, which allows you to filter the content and know if conditions are shared between tomes.

## Installation

1. Open **Manage Homebrew** in [5e.tools (2014)](https://2014.5e.tools/).
2. To install from GitHub, copy the **Raw JSON** link for your collection and paste it into the load-from-URL option. To install from disk, download the JSON and select it with the file upload option.
3. If you chose a community Brewathon and do not already have Project Moon or General Rules installed, also load **General Rules Compendium** to show the rules.

If you already installed an older release, I recommend to remove it and reinstall or click the update if done through the link.
